# 《当然可以好问题》Alice 像素 MV

时长 44.3 秒的单文件 HTML 动画，用于落地页。画面以像素风 Alice 为中心，带游戏式 HUD，节奏跟随歌曲卡点，无闪屏与镜头抖动。

## 运行

浏览器直接打开 `index.html`，点「播放」。需要保持同级的 `assets/` 与 `sprites/`。

| 参数 | 作用 |
|---|---|
| `?outfit=jk` | 指定服装：`jk`、`dress`、`chic`、`cardigan`，默认 `jk`；也可点界面上的「换装」 |
| `?embed=1` | 嵌入模式，去掉外边距与圆角，画面铺满窗口，播放控件保留 |
| `?t=10.3` | 停在指定秒数，用于截帧检查 |

```
预览/                  关键帧拼图与终版检查截图
```

## 角色素材怎么来的

1. 用 Alice 设定图加冒险岛纸娃娃画风图，生成第一张绿底像素站姿。
2. 以站姿为垫图生成其余动作。JK 制服是主衣服，13 个动作齐全。
3. 其余三套衣服用「JK 动作图 + 该服装站姿图」双垫图，把同一动作换上新衣服。
4. `pixel2svg.py` 把绿底图对齐到像素网格，输出 SVG；`build_sprites.py` 生成 `sprites/sprites.js`。

每张图的完整提示词、垫图顺序和成品对应关系见 `素材库/03_提示词/提示词.md`。

## 注意

- 绿幕原稿与 SVG 的网格间距要一致（每格约 3 像素），换装时人物大小与脚位才不会跳。具体参数见 `素材库/README.md`。
- 本目录不含 `process/` 下的过程截图（约 68 MB），需要时在原机器 `~/Movies/alice-mv/process/` 查看。
