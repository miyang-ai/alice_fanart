> 这里的角色是**虚构角色**，和 `refs/alice`、`refs/luoxiaoshan` 两位正典 IP 是两套东西，互不混框。
> 要新造一个这样的角色，走 [`workflows/opc-character/`](../../workflows/opc-character/README.md)。

## 每位角色的目录

```text
NN_<id>_<姓名>/
├── persona.json   人设卡：性格、价值观、原生家庭、小传、爱好、说话方式、口头禅、与 Alice 的关系、外貌等
├── spec.json      生图素材：外貌色值、服装、场景、动作、光线、头像朝向（可直接喂给 workflows/opc-character/build_prompts.py）
├── sheet.jpg      三视图定稿：头像和生活照的唯一垫图
├── avatar.webp    头像定稿，1024x1024（胸像构图）
└── life.webp      生活照定稿，1024x1536
```

`index.json` 是十三位的目录索引。

## 使用说明

- **当参考图**：做这些角色的新图（海报、表情包、朋友圈配图）时，只垫该角色的 `sheet.jpg`，沿用 `spec.json` 里的外貌色值与服装，
  并保持画风段不变，参见 `workflows/opc-character/style_anchor.zh-CN.txt`。
- **复现提示词**：`cp spec.json` 到新目录，用 `workflows/opc-character/build_prompts.py` 生成提示词。
- **图片规格**：头像和生活照是近无损 WebP（与线上展示用的是同一档），不是原始 PNG。本仓库不含更高分辨率的原图。

## 来源与注意事项

- 2026-10-01 的最终定稿。头像经过多轮校正：视线不再全部朝右上，改为正脸、朝左、朝右混搭；构图固定为胸部以上；
  动作按场景变化，不靠栏杆。完整来龙去脉见 `workflows/opc-character/README.md` 的「踩过的坑」。
- 魏博的三视图是试点阶段的定稿，头像按统一画风重画；其余十二位的三视图是批量生产的定稿。
- `spec.json` 里的 `avatar_pose` 等字段是最后一轮提示词素材。配音、内容评论家、调研员三位的头像定稿来自更早的一轮，
  与最后一轮素材描述的动作不完全一致，以 `avatar.webp` 为准。
- 魏博的人设（家庭与小传）为新写；2026-10-04 起 `persona.json` 补齐为与其余十二位相同的完整字段（性格内核、特质、价值观、爱好、口头禅、禁忌等）。
