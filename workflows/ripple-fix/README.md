# 数码涟漪修复工作流

成图放大后，亮部（光束、浅色叶片、天空）出现一圈圈同心的细碎纹路，细节发碎，这是 Image 2 系列模型偶发的「数字涟漪」。不用回去重抽，把图交给米羊 Lab 的修复工具处理，修完仍是这张图的构图、人物和氛围。

工具入口：<https://lab.miyang.cn/ripple/>

## 什么时候需要

- 100% 或放大查看时，亮部出现同心圆、网格、细密重复纹路
- 提示词塞了很多密集、重复的小细节（茂密植被、碎石、水纹、格纹），第一张就容易碎
- 同一提示词反复重抽，涟漪反而越来越重

先排查，再决定是否修复：

1. 把候选图放大到 100%，重点看光束、天空、大片浅色叶面
2. 构图、人物、氛围都满意，只是纹理碎，就走本工作流，不重抽
3. 构图或人物本身不对，直接重抽，不要修

## 流程

```text
正常生图（按 docs/垫图逻辑.md）
   │
   ▼
放大检查：亮部是否有涟漪
   │ 有
   ▼
上传到 https://lab.miyang.cn/ripple/ ──► 处理 ──► 下载修复图
   │
   ▼
对比修复前后，确认构图和人物没变 ──► 归档
```

## 使用方式

1. 打开 <https://lab.miyang.cn/ripple/>，拖入图片，或点击选择
2. 支持 PNG、JPEG、WebP，最大 40 MB、830 万像素（约 3840×2160），超出需要先缩小
3. 处理需要先用手机号注册并登录米羊账号。这个工具属于深度合成服务，法规要求先完成真实身份认证，无法跳过
4. 处理按米粒计费，产物存进你自己的米羊盘；高峰期处理名额有限，需要排队时会短信或邮件通知
5. 用页面的「长按预览」「放大镜」「分割线」对比修复前后，确认无误再下载

## 归档约定

修复前后都按 `docs/垫图逻辑.md` 第六节归档，放进同一事项目录：

- 修复前：`{character}_{kind}_v{n}.png`，状态改为 `superseded`，`superseded_by` 指向修复版，原因写「数码涟漪修复」
- 修复后：`{character}_{kind}_v{n+1}.png`，同名 `.prompt.json` 沿用原提示词，增加字段 `postprocess: "ripple-fix (lab.miyang.cn/ripple)"`，并写明修复前的文件名
- 修复后同样要重新过第七节的审计，尤其是 Alice 的穿衣红线和文字是否被改动

## 注意

- 工具会把整幅画面重画一遍，修完务必逐项核对：脸、手、衣物、文字、Logo 有没有被改
- 带文字的海报修复后，文字要逐字重新核对
- 尺寸要求严格的成品（如精确墙面比例），修复后检查尺寸，必要时按文档第十二节补边或裁切
- 图会上传到米羊服务器处理，涉及未公开素材时请自行评估
